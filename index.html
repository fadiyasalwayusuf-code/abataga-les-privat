Buat repository baru bernama `abataga` di akun `fadiyasalwayusuf-code`. 2. Pilih **Public** dan buat repository kosong (README boleh tidak dicentang). 3. Unggah `index.html` ke root repository, lalu commit. 4. Buka **Settings → Pages**. 5. Pada **Build and deployment**, pilih **Deploy from a branch**, pilih branch `main` dan folder `/(root)`, lalu Save. 6. Tunggu proses publikasi selesai. Alamat umumnya: `https://fadiyasalwayusuf-code.github.io/abataga/`. Catatan: pengaturan Pages dan alamat publik harus dicek di GitHub setelah repository dibuat. Jika username atau nama repository berubah, URL juga berubah.
